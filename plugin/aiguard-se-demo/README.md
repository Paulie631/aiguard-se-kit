# AI Guard SE demo plugin

Lets Claude set up, run and present the AI Guard SE demo kit for you: "set up the AI Guard demo", "populate my dashboards", "switch the demo policy to enforce", "keep my dashboard fresh", "tear it down".

Bundles a copy of the kit. Claude runs it on your own computer, so you need the Claude desktop app with access to your computer, plus `uv`. First-time setup asks for your OneAPI secret in your own terminal, never in chat.
